## 项目概述

**项目名称**: 云集智能网联代理专家
**核心功能**:
- 网络代理服务管理（基于 quick.exe 内核）
- 多线路自动检测与切换
- 全局系统代理 / 指定程序代理
- 系统浏览器自动检测与代理启动
- 定时自动线路优化

### ⚠️ 重要：Git管理范围与目录职责

| 目录 | Git管理 | 用途 | 说明 |
|------|---------|------|------|
| **dev/app/** (源码) | ✅ **Git管理** | 项目源代码 | Python源码、图标、依赖声明 |
| **docs/** | ✅ **Git管理** | 项目文档 | 开发指南等 |
| **dev/app/Quick/** | ❌ **Git不管理** | 代理内核 | 体积大，开发者本地放置 |
| **dev/*.exe** | ❌ **Git不管理** | EXE文件 | 体积大，通过构建脚本生成 |
| **build/** | ❌ **Git不管理** | 构建目录 | 按版本组织，方便回滚 |
| **BAK/** | ❌ **Git不管理** | 备份文件 | 旧版本备份 |
| **app/launcher_settings.json** | ❌ **Git不管理** | 运行时配置 | 用户本地设置 |

### dev/ 目录整洁原则

`dev/` 目录下**只放 EXE 文件**，所有其他文件归类到 `app/` 子目录：

| 文件类型 | 存放位置 | 说明 |
|----------|----------|------|
| EXE文件 | `dev/*.exe` | 构建产物 |
| 源代码/资源 | `dev/app/` | Python源码、图标、依赖声明 |
| 代理内核 | `dev/app/Quick/` | quick.exe + 配置 + GeoIP/GeoSite |
| 运行时配置 | `dev/app/launcher_settings.json` | 用户本地设置 |
| Python缓存 | `dev/app/__pycache__/` | 自动生成，.gitignore已忽略 |

### app/Quick/ 内置代理内核

项目将代理内核内置到 `app/Quick/` 目录，实现自包含：

| 文件 | 大小 | 用途 |
|------|------|------|
| `quick.exe` | ~30MB | Clash代理内核 |
| `config.yaml` | ~2KB | 代理配置（运行时由程序更新） |
| `Country.mmdb` | ~3.6MB | GeoIP数据库（quick.exe运行时依赖） |
| `GeoSite.dat` | ~1.8MB | 域名规则库（quick.exe运行时依赖） |

**内核查找优先级**：
1. `app/Quick/` — 内置内核（最高优先级）
2. 用户保存的路径 — 通过「选择内核目录」手动指定
3. 自动搜索 — 向上遍历目录查找 `*Quick*` 文件夹

### build/ 目录版本管理

构建目录按版本号组织，每个版本独立保存构建脚本和临时文件：

```
build/
├── build.py                    # 当前使用的构建脚本模板
├── v2026.05.08.1600/           # 版本构建记录
│   ├── build.py                # 该版本构建脚本备份（可用于回滚）
│   ├── build/                  # PyInstaller工作目录
│   └── dist/                   # PyInstaller输出目录
└── v2026.05.09.1000/           # 另一个版本
    ├── build.py
    ├── build/
    └── dist/
```

**回滚方法**：如需回滚到某版本，使用该版本目录下的 `build.py` 重新构建即可。

### 🚀 应用目录 (`dev/app/`)

| 文件/目录 | 用途 | 说明 |
|-----------|------|------|
| `dev/app/main.py` | 启动器主程序 | PyQt6 GUI，代理管理核心 |
| `dev/app/launcher.py` | 入口文件 | 调用 main.py 的 main() |
| `dev/app/icon.ico` | 应用图标 | Windows图标 |
| `dev/app/icon.png` | 高清图标 | PNG格式图标 |
| `dev/app/requirements.txt` | Python依赖 | PyQt6等 |
| `dev/app/version_history.json` | 版本历史 | 构建记录 |
| `dev/app/launcher_settings.json` | 运行时配置 | 用户本地设置（Git不管理） |
| `dev/app/Quick/` | 代理内核 | quick.exe + 配置 + 数据库（Git不管理） |

### 🔧 构建脚本 (`build/build.py`)

**构建命令**：
```bash
cd build/
python build.py
```

**构建流程**：
1. 动态生成版本号：`YYYY.MM.DD.HHMM`
2. 在 `build/v版本号/` 下创建版本构建目录
3. 将版本号注入 `dev/app/main.py` 的 VERSION 变量
4. PyInstaller 从 `dev/app/launcher.py` 构建 EXE
5. EXE 输出到 `dev/` 目录，文件名 `云集智能网联代理专家-vYYYY.MM.DD.HHMM.exe`
6. 构建完成后恢复源代码中的版本号
7. 自动清理旧版本 EXE
8. 将构建脚本备份到 `build/v版本号/build.py`，方便回滚

## 开发工作流

### ⭐ 标准开发流程

```
1. 日常开发 → 在 dev/app/ 修改和测试
   - 直接修改 main.py 等文件
   - 运行 python dev/app/launcher.py 测试

2. 构建EXE → 运行构建脚本
   cd build/
   python build.py

3. 测试EXE → 运行生成的EXE验证

4. Git提交 → 提交 dev/app/ 目录（Quick/会被自动忽略）
   git add dev/app/
   git commit -m "v版本号: 修改描述"
   git push
```

### 📝 Git 提交信息规范

**提交信息格式：`版本号: 简要描述`**

**示例：**
```
v2026.05.08.1600: 新增自动线路切换功能
v2026.05.08.1600: 合并浏览器设置到代理设置页面
v2026.05.08.1600: 修复线路检测超时问题
```

## 打包和发布

### 📦 发布整合包结构

```
发布目录/
├── 云集智能网联代理专家-vYYYY.MM.DD.HHMM.exe  # 启动器EXE
```

1. 下载整合包（EXE + app/Quick/）
2. 确保 EXE 与 app/ 目录在同一级
3. 运行 EXE，自动检测内置代理内核
