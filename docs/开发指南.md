## 项目概述

**项目名称**: 云集智能网联代理专家
**核心功能**:
- 网络代理服务管理（基于 quick.exe 内核）
- 多线路自动检测与切换
- 全局系统代理 / 指定程序代理
- 系统浏览器自动检测与代理启动
- 定时自动线路优化

## 核心文件说明

### 🚀 开发目录 (`dev/`)

| 文件/目录 | 用途 | 说明 |
|-----------|------|------|
| `dev/build.py` | EXE构建脚本 | 动态版本号，输出到 dev/ 目录 |
| `dev/app/main.py` | 启动器主程序 | PyQt6 GUI，代理管理核心 |
| `dev/app/launcher.py` | 入口文件 | 调用 main.py 的 main() |
| `dev/app/icon.ico` | 应用图标 | Windows图标 |
| `dev/app/icon.png` | 高清图标 | PNG格式图标 |
| `dev/app/requirements.txt` | Python依赖 | PyQt6等 |
| `dev/app/version_history.json` | 版本历史 | 构建记录 |

### 🔧 构建脚本 (`dev/build.py`)

**构建命令**：
```bash
cd dev/
python build.py
```

**构建流程**：
1. 动态生成版本号：`YYYY.MM.DD.HHMM`
2. 将版本号注入 `main.py` 的 VERSION 变量
3. PyInstaller 从 `dev/app/launcher.py` 构建 EXE
4. EXE 输出到 `dev/` 目录，文件名 `云集智能网联代理专家-vYYYY.MM.DD.HHMM.exe`
5. 构建完成后恢复源代码中的版本号
6. 自动清理旧版本 EXE

## 开发工作流

### ⭐ 标准开发流程

```
1. 日常开发 → 在 dev/app/ 修改和测试
   - 直接修改 main.py 等文件
   - 运行 python dev/app/launcher.py 测试

2. 构建EXE → 运行构建脚本
   cd dev/
   python build.py

3. 测试EXE → 运行生成的EXE验证

4. Git提交 → 提交 dev/ 目录
   git add dev/
   git commit -m "v版本号: 修改描述"
   git push
```

### 📝 Git 提交信息规范

**提交信息格式：`版本号: 简要描述`**

**示例：**
```
v2026.05.08.1600: 新增自动线路切换功能
v2026.05.08.1600: 合并浏览器设置到代理设置页面
v2026.05.08.1600: 修复线路检测超时问题
```

## 打包和发布

### 📦 发布整合包结构

```
发布目录/
├── 云集智能网联代理专家-vYYYY.MM.DD.HHMM.exe  # 启动器EXE
└── Quick/                                      # 代理内核（用户自行放置）
    ├── quick.exe
    └── config.yaml
```

### 用户使用流程

1. 下载 EXE 启动器
2. 将 EXE 放置到与 Quick 目录同级或上级目录
3. 运行 EXE，自动检测代理内核
4. 如未检测到，点击「选择内核目录」手动指定
