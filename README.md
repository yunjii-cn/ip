# 云集智能网联代理专家

一键智能代理，让网络畅通无阻。

## 功能特性

- **一键启停** — 开关代理只需一键，自动配置系统代理
- **多线路智能切换** — 支持4条线路并行测速，自动选择最快线路
- **定时优化** — 定时自动检测线路质量，始终保持最优连接
- **浏览器代理** — 支持全局代理或指定浏览器代理（Chrome/Edge/Firefox等）
- **版本管理** — 内置软件更新功能，支持多版本切换和硬链接映射
- **深色主题** — 精心设计的暗黑界面，护眼且美观

## 下载安装

1. 前往 [Releases](https://gitee.com/yunjii/ip/releases) 下载最新版本
2. 解压到任意目录
3. 运行 `云集智能网联代理专家.exe`

## 使用说明

1. 首次启动后，点击「启动代理」
2. 程序自动下载线路配置并启动代理内核
3. 在「线路检测」页面可手动测速和切换线路
4. 在「代理设置」页面可配置浏览器代理和定时优化

## 技术栈

| 技术 | 用途 |
|------|------|
| Python 3.12 | 开发语言 |
| PyQt6 | GUI框架 |
| PyInstaller | EXE打包 |
